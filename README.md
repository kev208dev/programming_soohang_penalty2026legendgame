## 📌 주요 기능 (Features)

* **국가 선택** : 12개의 국가중에서 선택할 수 있습니다! 13번은 얼굴인식!!(한국만 나오는 건 안비밀)

* **선수 명단 출력** : 선택한 국가의 키퍼 포함 선수 6명이 출력됩니다.

* **상대 매칭 화면** : 랜덤으로 상대 팀의 국가가 매칭됩니다.

* **경기 진행** : 사용자가 1,2,3 중 숫자를 입력하고 상대팀에서 랜덤으로 막는 방향의 번호와 비교되어서 선방/실축/골의 여부가 출력됩니다.

* **서든 데스** : 5라운드까지 승부가 안나면 서든 데스로 마지막 승부가 결정됩니다.

* **경기 결과 출력** : 마지막으로 경기결과가 출력됩니다.
